## This is For mobile Version of Rust not PC Version ##

## How to use

1. Pick the item from the dropdown
2. Type how many you want
3. Turn on the mixing table switch if you have one
4. Hit Calculate
5. The plan shows up as an image — tap it to send to Discord or wherever
